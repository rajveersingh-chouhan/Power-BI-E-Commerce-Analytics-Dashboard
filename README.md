# 📊 E-Commerce Analytics Dashboards

This repository contains interactive dashboards created in **Power BI** for analyzing e-commerce performance.

## 🔹 Dashboards Included
- **Sales & Revenue Dashboard**: Tracks total revenue, orders, customers, and monthly/category-wise trends.
- **Customer & Product Analysis Dashboard**: Highlights product revenue, customer demographics, and top city contributions.

## 📈 Key Insights
- Total Revenue: ₹1.17Cr (~$11.92M)
- Orders: 20K | Customers: 10K
- Average Order Value: ₹595.93
- Balanced revenue distribution across Male, Female, and Other customers
- Willow & Orion brands lead in product revenue

## 🛠 Tools Used
- Power BI
- Sample E-commerce dataset
